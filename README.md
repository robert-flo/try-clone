# try-clone

Clona repositorios de GitHub en un workspace de [`try`](https://github.com/tobi/try).

Destino por defecto: `$HOME/Dropbox/Work/tries` (se puede cambiar con `TRY_PATH`).

## Requisitos

- `bash`
- [`gh`](https://cli.github.com/) autenticado
- `try` en `PATH`

## Uso

```bash
chmod +x try-clone
./try-clone
```
